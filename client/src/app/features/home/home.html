Two libraries, one ASP.NET Core backend

  • @ismailza/ngx-auth-client owns the session. Pages only use AuthService, authGuard and authTokenInterceptor; the adapter is chosen from the server's configuration (currently {{ provider }}).
  • @ismailza/ngx-api-client owns every other call: versioned URLs (/api/v1/…), retry with backoff, problem+json errors normalised into ApiError, success toasts and the loading bar.

They meet in the interceptor chain — the bearer token is added innermost, so every retry is signed — and in ApiErrorHandler, which sends a 401 back to sign-in.
